# Task: Smart Bank – MySQL to Power BI Dashboard Project

## Project Objective

Create an end-to-end banking analytics project using the MySQL database created for Smart Bank. Develop an interactive Power BI dashboard to analyze banking data, identify business insights, and present meaningful conclusions through data visualization.

## Project Requirements

1. Explain the project objective and introduce the Smart Bank project.
2. Explain the project and its business purpose using the Power BI dashboard.
3. Connect the MySQL database to Power BI and use the available banking data.
4. Create an interactive, multi-page Power BI dashboard.
5. Use appropriate charts, graphs, tables, matrices, cards, maps, and other available Power BI visuals.
6. Create and use DAX measures and calculated columns wherever required.
7. Implement slicers, filters, conditional formatting, and other relevant Power BI features.
8. Implement report tooltips to display additional information.
9. Implement drill-down functionality for hierarchical data analysis.
10. Implement drill-through functionality for detailed analysis.
11. Use buttons and page navigation for dashboard navigation.
12. Implement bookmarks to create interactive dashboard views.
13. Apply appropriate formatting, themes, titles, labels, and a consistent dashboard layout.
14. Ensure that all dashboard pages are interactive and provide meaningful business insights.
15. Present the final dashboard and explain the insights obtained from the analysis.

## Final Deliverables

* MySQL database used for the Smart Bank project.
* Power BI report containing multiple interactive dashboard pages.
* Implementation of relevant Power BI features and functionalities.
* Project explanation covering the objective, analysis, business insights, and conclusion.

## Conclusion

Present the final findings of the Smart Bank project and explain how the Power BI dashboard helps analyze banking operations, understand business performance, and derive meaningful insights from the available data.
